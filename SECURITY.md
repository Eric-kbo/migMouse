# Security Policy

## Supported versions

MigMouse is currently in its first public development milestone. Security fixes are applied to the latest version on the `main` branch.

## Reporting a vulnerability

Please report security issues privately through GitHub's **Security → Report a vulnerability** feature. Do not open a public issue for a vulnerability that could put users at risk.

Include the affected version or commit, macOS version, reproduction steps, impact, and any suggested mitigation. Please avoid including unrelated personal data.

## Privacy and permissions

MigMouse processes Magic Mouse touch data locally and does not transmit it. Accessibility permission is used to post synthetic mouse clicks; Input Monitoring is used to arbitrate taps against scrolling and physical clicks. The app contains no analytics or telemetry.
